# Notion ZIP 带图导入实施计划

**目标**：用户从 Notion 导出单篇页面的 Markdown & CSV ZIP，在排版工具选择 ZIP 后得到正文、图片预览，并可复制到公众号及导出独立 HTML。

**架构**：浏览器本地解压 ZIP，选择顶层 Markdown，按 ZIP 内相对路径匹配图片并生成当前会话可用的 object URL。导入前完成校验；复制和导出 HTML 时将这些本地图片转为 data URL。无需服务器、Notion 账号授权或上传文章。

**技术**：React、TypeScript、Vite；使用 ZIP 解压库作为项目依赖；沿用 markdown-it、Vitest、Playwright。

**范围**：单篇页面。若导出包有多个候选首页且无法唯一确定，明确报错；子页面不合并到正文。保留用户现有未提交改动，不推送或部署。

## 主要风险与验收

- 大图片可能使浏览器内存上涨；解析前后限制文件大小、数量和总解压量，超出时拒绝并保留草稿。
- Notion 导出包可能有多种目录层级；优先用真实导出包验收，并明确不支持的结构。
- 外部远程图片不属于 ZIP 内资源；导入时单独统计并提示，不能把未打包的远程图片当成“已带图”。
- 验收标准：一个含多张本地图片的单篇 ZIP 一次导入后图片顺序正确；复制到公众号与导出 HTML 不含临时 blob URL；失败不改编辑器内容。
